# AI-Interview-Proctor
AI Interview Proctor is an AI-powered interview monitoring system built with YOLOv8, MediaPipe, OpenCV, and Streamlit. It detects suspicious objects and head movements, calculates a cheating score, and generates annotated videos, CSV/PDF reports, and a live dashboard for automated interview analysis.

## Features
- **Live Dashboard & Status Panel**: Real-time evaluation of candidate trust scores and focus tracking.
- **Automated Warning System**: Flags tab switches, multiple faces, or background audio anomalies.
- **Evidence Management**: Instant snapshot capture and report downloads.
- **Streamlit Interface**: Lightweight, highly responsive UI built for recruiters and administrators.

## Quickstart Installation
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
